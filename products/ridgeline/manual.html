Ridgeline - manual (draft)

Ridgeline is in research and is not yet released. This page describes the idea, the settings and what to expect.

The idea

Price has to climb over a ridge before a breakout is real. Ridgeline waits for a confirmed swing high or low on the daily chart, places a pending stop just beyond it, and trades only if price breaks through.

Settings: start at the top

Ridgeline runs with no settings file. The first group, Start here, is all most users touch: - Settings: Recommended (the validated values) or Custom. Everything in the Custom group is ignored unless this is Custom. - Risk level: Low (half size), Medium (the validated size), High (double size). The base size is defined for an account of ten thousand dollars and scales with account equity. - Virtual balance: size as if the account held at most this much. 0 = off. - Maximum spread in USD: no new order is placed while the spread is wider. 0 = off. In USD, not points, so it means the same on every gold quote.

Attach it to a gold chart (XAUUSD, any suffix) on H1. It refuses any other symbol or timeframe.

Risk handling

  • A hard stop is set when the order fills. The stop distance is 0.72 times gold's own 14-day average daily range, so it follows volatility.
  • Target is one stop distance; a trailing stop starts at a quarter of the stop distance and trails one stop distance behind price.
  • Each level is traded once; an untouched order is removed when the level is no longer relevant (205 hours at most).
  • One position at a time. No martingale, grid or averaging.

What to expect

  • Few trades: roughly 30 to 70 a year.
  • Results depend on the market regime. Breakout systems earn in trending phases and give back in quiet or choppy ones.
  • Run on a demo account first. Tester results do not predict future results.

Input reference

Group Input Type Default Meaning
1. Start here InpProfile RL_PROFILE RL_RECOMMENDED Settings: Recommended / Custom
1. Start here InpRiskLevel RL_RISK RL_MEDIUM Risk level (Low 0.5x, Medium 1x, High 2x)
1. Start here InpVirtualBalance double 0.0 Size as if the account held at most this (0 = off)
1. Start here InpMaxSpreadUsd double 0.0 Maximum spread in USD (0 = off)
2. Custom (only with Settings = Custom) cStopAtrMult double 0.72 Stop = this x gold's daily range (14 days)
2. Custom (only with Settings = Custom) cRelTarget double 1.0 Target = this x the stop distance
2. Custom (only with Settings = Custom) cRelTrailSize double 1.0 Trailing gap = this x the stop distance
2. Custom (only with Settings = Custom) cRelTrailStart double 0.25 Trail starts at this x the stop distance
2. Custom (only with Settings = Custom) cExpiryHours int 205 Resting order lifetime (hours)
